Frequently Asked Questions
What is the tallest machine in the dataset? +
The Bagger 288 is the tallest at 96 meters, followed by Big Muskie at 68 meters.
How does the scale comparison work? +
The visualization uses a logarithmic-ish scale to fit all machines into the canvas view. Heights are normalized against the maximum value (Bagger 288 at 96 m). Human reference is approximately 1.8 m tall for scale.
What does "Copy Scenario Link" do? +
It generates a URL-encoded link that preserves your current slider positions and highlight index, so you can share an exact view with others.
Can I export the data? +
Yes, the "Export CSV Telemetry" button generates a CSV file containing the current scale factors and the full dataset for offline analysis.
What is the significance of the Caterpillar 797F? +
The Caterpillar 797F is a haul truck, which is measured by length (14.8 m) rather than height. It's included for comparison to show different machine types.
