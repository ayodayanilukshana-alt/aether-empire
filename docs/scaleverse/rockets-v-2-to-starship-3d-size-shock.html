FAQ

How is the scale factor applied?

The global scale slider multiplies the base height of every rocket by the same factor (0.5× to 2.0×). This does not change relative proportions between rockets — only the overall visual and telemetry scale.

What does "V-2 Units" mean?

It represents how many times the V-2 rocket's height (14 m) fits into the currently selected rocket. For Starship (121 m) this is 8.64×.

Can I export the current telemetry?

Yes. The Export CSV Telemetry button generates a CSV file containing all rocket data, current scale factor, and derived ratios.

How do I share the current scenario?

Click Copy Scenario Link to copy a URL with query parameters (selected rocket and scale factor) to your clipboard.
