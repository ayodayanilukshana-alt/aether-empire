FAQ · Scale & simulation
Why is the blue whale 30 m and not 33 m? +
The payload specifies 30 m for the blue whale (typical adult length range is 24–30 m). We use exactly 30.0 m for consistency with the provided dataset.
How is the "scale factor" applied? +
The scale slider multiplies all lengths in the 3D view uniformly. The KPI values remain in true metres, but visual spacing changes to help compare tiny and huge mammals.
What does "mass range ~50M×" mean? +
The Etruscan shrew weighs ~1.8 g, the blue whale ~150,000,000 g. 150,000,000 / 1.8 ≈ 83 million. Using the payload's mass values (1.8 g vs 150,000 kg = 150,000,000 g) gives ≈83.3 million, but the video's summary states 50 million×; we display both.
Can I export the exact data? +
Yes — click "Export CSV Telemetry" to download a CSV file containing all species, lengths, mass figures, and current slider values.
