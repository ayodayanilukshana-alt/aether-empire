FAQ

How were the sizes measured?
Length estimates are based on peer-reviewed fossil analyses and represent typical adult sizes. Deinonychus ≈ 1.5 m, Mosasaurus ≈ 17 m.
Can I export the current scenario?
Yes — click “Export CSV Telemetry” to download a CSV with all current slider values and KPIs. “Copy Scenario Link” copies a shareable URL with all parameters encoded.
What do the preset buttons do?
They instantly set all five sliders to specific configurations: “Original Data”, “Max Scale”, “Raptor Focus”, “Marine Dominance”, and “Balanced”.
Is this a 3D model?
The main view is a 2D scale comparison canvas (optimized for clarity). It accurately reflects real-world lengths using a 1 meter = 1 unit scale.
