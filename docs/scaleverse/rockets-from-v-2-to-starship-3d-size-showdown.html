Frequently Asked Questions

It compares the physical stacked height (in meters) of five historic launch vehicles from the video dataset: V-2 Rocket (14 m), Falcon 9 (70 m), Saturn V (110.6 m), SpaceX Starship (121 m), and Starship with Super Heavy (121 m). All values are drawn directly from the DATA payload, and the canvas renders them to a common ground baseline at an adjustable pixels-per-meter scale.
The dataset records both entries at 121 m (397 ft). This reflects the video's simplified comparison metric. In this workstation they are rendered as distinct items so you can inspect each independently — the "with Super Heavy" preset is treated as the apex reference in the stack.
The KPI "Ratio (Tallest / V-2)" = tallest height ÷ V-2 height = 121 ÷ 14 = 8.643×. This is computed dynamically from the dataset on every reload, never hardcoded, so adjusting the reference in future versions updates the readout automatically.
Viewport Scale (px/m) sets how many pixels represent one meter on the canvas. Rocket Spacing sets the horizontal gap between rendered vehicles. Ground Offset shifts the shared ground baseline. Opacity / Ghost fades non-reference rockets so the selected baseline stands out. Every control re-renders immediately and updates the "Rendered (px)" column.
The export contains one row per rocket with index, name, height in meters, height in feet, ratio vs V-2, rendered pixel height at the current scale, and percentage share of the total stack (436.6 m). It also includes a header with the active scenario parameters (scale, spacing, ground offset, opacity, reference rocket) so the exact scenario can be reproduced.
It serializes the current control state (scale, spacing, ground offset, opacity, and selected reference) into URL query parameters and copies the resulting canonical URL to your clipboard. Opening that link restores the scenario on load via URL parameter parsing.
