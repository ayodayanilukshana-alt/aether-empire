Frequently Asked Questions
What does the "meters" field represent?
The meters value is a scale reference provided in the dataset. It is used here as a visual multiplier for the canvas representation, not as an actual physical dimension.
How are the capacities adjusted?
Each slider multiplies the original seat count by a factor between 0.2× and 2.5×. The KPI cards and canvas update in real time.
What does "Export CSV Telemetry" produce?
A downloadable CSV file containing the current adjusted capacities, original capacities, and scale multiplier for each stadium.
Is the scenario link shareable?
Yes. The "Copy Scenario Link" button copies a URL containing query parameters that encode all current slider positions, so you can share your exact scenario.
