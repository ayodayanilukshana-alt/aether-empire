FREQUENTLY ASKED QUESTIONS
What does the "Fortress Index" represent?
A weighted aggregate of all five facilities' security parameters—cryo stability, bullion tonnage, depth, secrecy, and gold bar count—normalized to a 0–100 scale.
How are the slider values interpreted?
Each slider directly maps to the metric of the corresponding facility. For example, moving the Svalbard slider changes the cryo temperature (from -40°C to 0°C), which alters the visual and KPI readouts.
Is the CSV export dynamic?
Yes. The export button generates a CSV file containing the current slider values and calculated security ratings for all five items, timestamped for telemetry.
Why is Area 51 labeled "TOP SECRET"?
The slider (1–10) represents secrecy level; values 8–10 map to "TOP SECRET", while lower values unlock different classification labels.
