What physics engine powers this simulation?
This workstation uses Matter.js, a 2D rigid-body physics engine configured for 60 FPS with custom collision impulse telemetry and real-time escape velocity tracking.
How are the Marvel and DC teams modeled?
Each team is represented by an abstract mass-spring aggregate with distinct restitution, friction, and velocity profiles. The Marvel group uses a lighter, higher-elasticity profile; DC uses a heavier, more damped profile.
Can I export the telemetry data?
Yes. The "Export CSV Telemetry" button generates a CSV file containing live kinetic metrics, collision impulses, and team velocity data from the simulation.
What does "Copy Scenario Link" do?
It copies a canonical URL that encodes the current slider and preset state, allowing you to share the exact physics configuration with colleagues.
