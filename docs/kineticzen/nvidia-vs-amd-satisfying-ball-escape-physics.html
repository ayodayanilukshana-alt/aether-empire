FAQ

What does the simulation represent?

It is a visual rivalry model using circular bodies, gravity, walls, pegs, friction, and an exit gate. It is inspired by the supplied Matter.js physics concept and does not represent benchmark performance.

How are NVIDIA and AMD compared?

Both teams receive equivalent ball bodies and begin in separate labeled lanes. The live comparison is based on escaped balls and elapsed time.

What is recorded in telemetry?

The CSV contains timestamp, escape counts, collision count, active bodies, and leader state at regular intervals.
