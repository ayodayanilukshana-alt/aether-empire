Frequently Asked Questions

What physics engine powers this simulation?

This is a custom 60FPS rigid-body physics simulation using circle-circle and circle-wall collision responses with energy restitution. Matter.js-inspired integration but built from scratch for real-time performance.

How do the speed multipliers affect the duel?

Each slider controls the target speed of the respective ball. Higher multipliers give the ball more momentum but also increase collision frequency and reduce directional control in the maze.

Can I export the live telemetry data?

Yes, the "Export CSV Telemetry" button captures the current physics state (velocity, kinetic energy, collisions, progress) and downloads it as a spreadsheet-ready file.

What does "Copy Scenario Link" do?

It copies a URL with encoded parameters representing your current slider configuration, so you can share this exact physics scenario with others.
