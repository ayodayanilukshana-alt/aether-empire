FREQUENTLY ASKED QUESTIONS hero ball physics
What exactly is the "Hero Ball Physics Escape" simulation?
It is a real-time rigid-body simulation that pits MARVEL against DC in a 60 FPS collision arena. Balls representing heroes from each team bounce, transfer momentum, and escape through gravitational and restitution forces.
How are the physics parameters controlled?
Use the four sliders (gravity, restitution, mass ratio, time scale) to alter the simulation in real time. Preset buttons instantly apply curated parameter sets like "Low Gravity", "Bouncy", or "Slomo".
Can I export telemetry data?
Yes. The "Export CSV Telemetry" button downloads a CSV file containing the current velocity, momentum, and collision statistics for every active body.
How do I share the current scenario?
Click "Copy Scenario Link" to copy a URL with the current slider values embedded as query parameters. Anyone opening that link will see your exact configuration.
Is this built on Matter.js?
The core physics engine is a custom implementation inspired by Matter.js rigid-body dynamics, optimised for 60 FPS canvas rendering and real-time parameter updates.
